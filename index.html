JVBuilt's Garage

The JVBuilt repository and build update source.

Download the Kodi repository

  1. Install the repository ZIP in Kodi using Install from zip file.
  2. Choose Install from repository → Jake Community Add-ons → Program add-ons → JVBuilt's Garage.
  3. Open Garage to check for a build update.

Build installation erases the existing Kodi profile after download and validation. External media is retained.
