JVBuilt Kodi Repository

The JVBuilt repository and build update source.

Download the Kodi repository

  1. Install the repository ZIP in Kodi using Install from zip file.
  2. Choose Install from repository → Jake Community Add-ons → Program add-ons → JVBuilt's Garage.
  3. Update Garage to 2.0.9.18 or later, restart Kodi, and choose the shared JVBuilt 6 build for any supported device.

Garage 2.0.9.18 enables available English subtitles at movie and episode startup, or continues without subtitles when English is unavailable.

The current installer stages and verifies the build, preserves this device's personal configuration, and retains its previous Kodi folder for recovery. Install the Garage update before updating the build; older installers perform a full reset.
