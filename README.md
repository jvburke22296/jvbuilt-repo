# JVBuilt Kodi Repository

Public Kodi update distribution. This repository contains the published catalog, add-on packages, and artwork. Full build ZIPs are distributed through Releases.

[Install the repository](https://raw.githubusercontent.com/jvburke22296/jvbuilt-repo/main/repository.jake.community-1.0.8.zip)

## JVBuilt and Sports

Install **JVBuilt and Sports 1.1.0** from this repository for the saved JVBuilt PVR list or the NFL/NBA Sports list. Kodi closes after a successful playlist choice; reopen it to load the selection. IPTV Simple and the original video add-ons used by plugin streams are required.

## Build updates

Garage 2.0.9.19 uses the device-preserving update behavior. Updating JVBuilt keeps the existing Kodi profile, including accounts and device settings, instead of performing a clean reset.
