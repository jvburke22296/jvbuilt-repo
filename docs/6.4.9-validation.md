# JVBuilt 6.4.9 validation

November 1, 2026.

- MS NOW was played and visually identified in Kodi. It is first in the Live TV home widget; the other channels remain available. The widget resolves each device's native PVR channel path from its current channel database.
- Mad Titan Adaptive playback requests a 45-second live-edge delay. The Lions shortcut uses the same value. A local service adjusts supported direct live HLS/DASH playback windows and builds a 45-second startup pause for PVR.
- IPTV Simple timeshift is enabled. FFmpeg Direct's timeshift disk buffer is limited to 15 minutes. Tests observed normal playback after the startup pause: MS NOW reported a 45-second offset, and the Lions PVR channel approximately 48 seconds. Segment boundaries, provider windows and stalls affect timing; short or unseekable sources cannot be promised an exact delay.
- Six live/VOD classification checks passed, including VOD behind a master playlist remaining excluded. Seven Lions refresh, fallback and routing regression checks passed.
- During the earlier live NFL pass, seven of eight then-live games were visually verified with advancing game video. Ravens–Bills had no working verified feed; its tested routes failed TLS, segment access or HTTP 403/404. This was a time-specific test, not a guarantee of later availability. Intermittent stalls were observed on some working feeds. Spoken English was not independently verified.
- The Sports menu, November 1 Lions refresh route, five-sport scope, national channels, source filtering and cancellation fix are included. Existing 1994 intro and installer fixes are retained.
- The release archive passed CRC and clean-install validation. Its clean add-on registry retains the baseline entries and enables the new helper. Personal profile settings and private playback logs were excluded. The live-game fallback is an expiring public stream token retained at the user's request; it is not a subscription credential.
- Archive and add-on SHA-256 sidecars use LF line endings for Kodi's checksum parser. Public catalog and artifact hashes are checked before the feed is published.

Install the complete 6.4.9 build through JVBuilt's Garage to apply the home widget and PVR profile preferences. Repository packages also include Mad Titan 2.0.47.1, JetExtractors 3.3.30.2 and JVBuilt Live Delay 1.0.0. This release does not automatically update devices that have not installed it.
